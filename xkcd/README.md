# Pranking Randall Munroe

Randall Munroe ran a "What If" column for a while.
One of the questions posed was "What if Google held all their data on punched cards?"

Using data from the annual report and industry figures on disk sales he did a surprisingly good estimate of the amount of disk capacity we had at that time.
Someone decided he needed to be acknowledged, so they came up with the prank here.

I won't claim credit for the puzzle.  My part was merely to produce the final set of punched cards.
The files here include code to produce an svg image of a card, so we could laser cut them.
Laser cutting keypunch cards is a bad idea.

Long story short, he appreciated the joke. And talked about it in a TED talk.
